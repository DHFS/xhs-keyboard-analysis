      08 / INCREMENTAL WORKFLOW

      以后新增评论：去重、初筛、复核、联动刷新

      当前基线是人工语义审定结果；更新工具只处理新评论ID，不会把565条基线评论重复计入。

      1. 首次初始化基线
        对当前这份原始CSV执行一次左侧命令。它只登记评论ID，不改变当前人工审定评分。
      2. 未来导入更新后的CSV
        可传完整新导出，也可只传新增评论。工具按ID去重，原文件只读。
      3. 复核不确定评论
        多品牌比较、争论、短回复和模糊立场会待复核；高置信度单品牌评论自动计入。
      4. 刷新与导出
        报告、筛选表和CSV导出同步变化。新别名在 coding_rules.json 中维护，不改历史原文。

      在 keyboard_analysis 目录运行

      # 第一次：登记当前基线评论ID python update_analysis.py --init "C:\Users\admin\Desktop\xhs-keyboard-comments-full.csv" # 以后：加入更新后的完整CSV python update_analysis.py --update "你的新CSV完整路径.csv" # 复核模糊评价（y计入 / p好评 / n差评 / u中立 / x排除） python update_analysis.py --review # 查看状态 / 仅重新生成报告 python update_analysis.py --status python update_analysis.py --rebuild

      依赖：Python 3，仅使用标准库。修改 annotations.json 后可执行 --rebuild。若新增品牌无法识别，把别名加入 coding_rules.json 后再处理新评论；已排除的旧记录不会被盲目重算。

      09 / METHODOLOGY

      评分方法与维护边界

      统计单位

      一条评论同时评价两个品牌，可分别计入两个品牌；同一品牌在同一评论中只计一次。点赞不加权，同一作者连续回复不视作完全独立样本。

      好评率 = 好评数 / 相关评论数
      差评率 = 差评数 / 相关评论数
      中立率 = 中立模糊数 / 相关评论数

      情感口径

      明确推荐、满意或显著优于竞品为好评；不推荐、故障、品控／售后问题为差评；拥有、询价、指代不明或好坏并存为中立模糊。纯人身攻击不计。

      净分 = (好评数 − 差评数)
      　　　 / 相关评论数 × 100

      自动化边界

      新增评论的语义立场不能靠简单计数公式可靠生成。本工具自动做明确规则初筛，把复杂语义留给人复核；评分表和报告则会随审定标注自动耦合更新。

      基线人工审定 + 新增高置信标注
      + 新增人工复核 = 当前报告
      结论边界：本报告反映该小红书帖子中的口碑结构，不是随机抽样、实验室测试或真实故障率。任何型号都应在下单前核实现价、批次、轴体与售后。
